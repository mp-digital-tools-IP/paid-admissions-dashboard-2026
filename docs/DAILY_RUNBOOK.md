# Ежедневный регламент

1. Поместить полную новую выгрузку договоров в локальную папку проекта. Git игнорирует Excel, PDF и временные выгрузки.
2. Указать фактическое время среза с часовым поясом Москвы.
3. Запустить `tools/depersonalize_contracts.py` (или `tools/update-and-check.ps1`) по примеру из README. Обработчик использует исходные персональные поля только в оперативной памяти.
4. Проверить отчёт: оплата по всем детальным строкам, уникальные договоры, уникальные люди и дубли.
5. В блоке сверки убедиться, что итоговая строка Excel совпадает с суммой деталей; расхождение должно быть 0 ₽.
6. Проверить приоритеты 1 и 2, один факультет с гражданством, магистратуру с собственной целью ПФХД и мобильную ширину.
7. В Git добавить только код, документацию и агрегаты `public/data`.
8. После проверки создать коммит и отправить `main`. Неуспешная Pages-сборка не заменяет действующий сайт.

Обработка останавливается до изменения `current.json`, если отсутствует обязательная колонка или лист, изменился план без `--allow-plan-change`, найден конфликтующий дубль, отрицательная сумма либо возможные персональные данные. Несопоставленные направления публикуются в агрегированном виде и показываются в качестве данных, чтобы полный финансовый итог не скрывался.
