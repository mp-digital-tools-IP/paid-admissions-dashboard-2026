# Ежедневный регламент

1. Поместить полную новую выгрузку договоров в локальную папку проекта. Старые выгрузки можно хранить локально: Git их игнорирует.
2. Указать фактическое время среза с часовым поясом Москвы.
3. Запустить `tools/update-and-check.ps1` по примеру из README.
4. Проверить напечатанный отчёт: активные, подписанные, оплаченные, оплату, портфель и дубли.
5. Открыть локальную production-версию и проверить общий срез, один факультет и мобильную ширину.
6. В Git добавить только код, документацию и агрегаты `public/data`. Excel добавлять запрещено.
7. После проверки создать коммит и отправить `main`. GitHub Pages сохраняет предыдущий действующий сайт, если сборка завершится ошибкой.

Обработка должна остановиться до изменения `current.json`, если отсутствует колонка или лист, изменился план, появился несопоставленный код, конфликтующий дубль, отрицательная сумма либо возможные персональные данные в публичном JSON.
