# Контракт данных

## План ПФХД

Источником являются детальные строки `ПФХД2 (13.08.2026).xlsx` на листах:

- `Москва` — бакалавриат и специалитет;
- `Магистратура`;
- `Аспирантура`.

Формы идут в порядке: очная, очно-заочная, заочная. Контроль детального плана: ПФХД — 1 215 договоров, маркетинговая цель — 5 068. Групповые итоги не подменяют детали и показываются в качестве данных.

Цель выбранного среза пересчитывается по уровню, форме, факультету и направлению. Она не делится по гражданству, скидке или приоритету, потому что таких измерений в ПФХД нет.

## Договоры

Обработчик читает все детальные строки с непустым номером договора. Ничего не исключается из полного факта по приоритету или статусу.

- `Оплата по выгрузке` — сумма оплаты всех детальных строк, включая точные повторы;
- `После удаления дублей` — сумма оплаты по уникальным номерам договоров;
- `Портфель` — сумма уникальных подписанных договоров за первый семестр после скидки;
- `Оплаченные договоры` — уникальные договоры с оплатой больше нуля;
- `Уникальные люди` — одно нормализованное ФИО один раз независимо от количества приоритетов и договоров;
- гражданство — `Россия` или `Иностранное`;
- скидка — `Размер скидки > 0`;
- стоимость семестра — фактическое значение из выгрузки, при нескольких значениях показывается диапазон.

Итоговая строка Excel с пустым номером договора хранится только как контрольная сумма. Несопоставленные направления не скрываются: они остаются в факте с нулевым планом и попадают в качество данных.
