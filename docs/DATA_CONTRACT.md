# Контракт данных

## План ПФХД

Источником являются детальные строки `ПФХД2 (13.08.2026).xlsx` на листах:

- `Москва` — бакалавриат и специалитет;
- `Магистратура`;
- `Аспирантура`.

Формы идут в порядке: очная, очно-заочная, заочная. Контроль детального плана: ПФХД — 1 215 договоров, маркетинговая цель — 5 068. Групповые итоги не подменяют детали и показываются в качестве данных.

Цель выбранного среза пересчитывается по уровню, форме, факультету и направлению. Она не делится по гражданству, скидке или приоритету, потому что таких измерений в ПФХД нет.

## Договоры

Обработчик читает все детальные строки с непустым номером договора. Ничего не исключается из полного факта по приоритету или статусу.

- `Оплата по выгрузке` — сумма оплаты всех детальных строк, включая точные повторы;
- `После удаления дублей` — сумма оплаты по уникальным номерам договоров;
- `Портфель` — сумма уникальных подписанных договоров за первый семестр после скидки;
- `Оплаченные договоры` — уникальные договоры с оплатой больше нуля;
- `Уникальные люди` — одно нормализованное ФИО один раз независимо от количества приоритетов и договоров;
- гражданство — `Россия` или `Иностранное`;
- скидка — `Размер скидки > 0`;
- стоимость семестра из выгрузки используется только как третий источник для справочника годовой стоимости и не показывается диапазоном.
- Новые поля `Код специализации` и `Профиль` используются только локально: сначала соединяется базовый код с суффиксом специализации, затем проверяется точное наименование профиля. Если профиль не задан, факультет разрешает одноимённое направление; пустой уровень восстанавливается лишь при единственном варианте по форме и коду. Неоднозначная строка останавливает обновление до публикации.

Итоговая строка Excel с пустым номером договора хранится только как контрольная сумма. Несопоставленные направления не скрываются: они остаются в факте с нулевым планом и попадают в качество данных.


## Стоимость обучения

Публичный справочник tuition.json хранит одну стоимость первого года для каждой отдельной комбинации «уровень + форма + код + наименование».

1. Основной источник — приказ № 392-ОД от 08.04.2026: годовая стоимость используется напрямую.
2. Если строки нет в приказе — годовая «Стоимость ОП» из плана ПФХД.
3. Если цены нет в обоих источниках, но есть договоры — наиболее частая «Стоимость семестра × 2».

Очная, очно-заочная и заочная формы никогда не объединяются в одну строку. Диапазоны стоимости не публикуются. Контрольная база содержит 124 строки приказа и 2 дополнительные строки из ПФХД — всего 126 записей с ненулевой ценой. Семь активных плановых строк без цены ни в одном источнике остаются в локальном отчёте проверки и не подменяются оценкой.
