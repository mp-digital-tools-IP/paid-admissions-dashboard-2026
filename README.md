# Дашборд платного приёма — 2026

Публичный статический дашборд Московского Политеха для ежедневного контроля платного приёма. В репозитории находятся только агрегированные данные: исходные Excel, ФИО и номера договоров исключены из Git и интерфейса.

## Что показывает дашборд

- финансовый прогресс к цели 178 млн ₽ и ориентир 2025 года 279 млн ₽;
- активные, подписанные и оплаченные договоры;
- портфель подписанных договоров после скидки и фактическую оплату раздельно;
- план ПФХД и маркетинговую цель по уровням, формам, факультетам и направлениям;
- гражданство, наличие скидки, динамику и контроль качества загрузки.

## Ежедневное обновление

Исходные файлы должны оставаться локально в корне проекта. Выполните одну команду из PowerShell:

```powershell
.\tools\update-and-check.ps1 -Plan ".\ПФХД2 (13.08.2026).xlsx" -Contracts ".\Выгрузка договор от 14.08.2026.xlsx" -SnapshotAt "2026-08-14T22:30:00+03:00"
```

Команда проверяет схему, сопоставление всех кодов, контрольные суммы плана и приватность, заменяет срез той же даты без дубля, запускает тесты и production-сборку. При любой ошибке `current.json` не меняется.

План ПФХД неизменен. Если его официально согласованная версия действительно изменилась, отдельно выполните обработчик с флагом `--allow-plan-change`; не объединяйте это с обычным ежедневным обновлением.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
pnpm install --frozen-lockfile
pnpm run dev
```

Проверка перед фиксацией нового среза:

```powershell
pnpm run check
pnpm run test:e2e
```

Публикуются только `public/data/plan.json`, `current.json`, `history.json` и дневные агрегаты из `public/data/snapshots/`. Развёртывание выполняет GitHub Pages workflow после отправки проверенного коммита в `main`.

## Безопасность

- `*.xlsx`, `*.xls`, `*.csv` и временные каталоги исключены до первого коммита;
- обработчик не записывает ФИО и номер договора в JSON или консоль;
- публичные артефакты проходят отдельный privacy-скан;
- сайт статический: без авторизации, загрузки Excel в браузер и серверного хранилища.
