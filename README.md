# Дашборд платного приёма — 2026

Публичный статический дашборд Московского Политеха для ежедневного контроля платного приёма. В репозитории находятся только агрегированные данные: исходные Excel/PDF, ФИО и номера договоров исключены из Git и интерфейса.

Публичная версия: https://mp-digital-tools-ip.github.io/paid-admissions-dashboard-2026/

## Что показывает дашборд

- оплату по текущей выгрузке и прогресс к цели;
- уникальных людей и уникальные договоры;
- все приоритеты, статусы, гражданство и скидки;
- портфель подписанных договоров после скидки;
- ПФХД и маркетинговую цель по уровням, формам, факультетам и направлениям;
- одну стоимость первого года по каждой программе и форме: приказ — основной источник, ПФХД — второй.

Главный экран рассчитан на два сценария: общий управленческий обзор и срез декана по своему факультету. Каждый факультет отображается один раз; уровень, форма, направление, приоритет, гражданство и скидка задаются фильтрами. При академическом фильтре цель пересчитывается по строкам ПФХД выбранного среза.

## Обновление справочника стоимости

При замене приказа или плана ПФХД справочник стоимости пересобирается отдельно:

    python tools/build_tuition_reference.py --order "Стоимость обучения.pdf" --plan "ПФХД2 (13.08.2026).xlsx" --contracts "Выгрузка договор от 13.08.2026.xlsx" --output "public/data/tuition.json"

В справочник публикуется одна годовая сумма. Формы обучения не объединяются, исходные PDF/Excel остаются только локально.
## Ежедневное обновление

Исходные файлы остаются локально в корне проекта. Выполните из PowerShell:

```powershell
.\tools\update-and-check.ps1 -Plan ".\ПФХД2 (13.08.2026).xlsx" -Contracts ".\Выгрузка договор от 14.08.2026.xlsx" -SnapshotAt "2026-08-14T22:30:00+03:00"
```

Команда проверяет схему, контрольные суммы плана, дубли и приватность, заменяет срез той же даты без дубля, запускает тесты и production-сборку. План ПФХД изменяется только отдельным запуском с `--allow-plan-change` после согласования.

## Локальный запуск и проверка

```powershell
python -m pip install -r requirements.txt
pnpm install --frozen-lockfile
pnpm run dev
```

```powershell
pnpm run check
pnpm run test:e2e
```

Публикуются только очищенные public/data/plan.json, tuition.json, current.json, history.json и дневные агрегаты. Развёртывание выполняет GitHub Pages после отправки проверенного коммита в `main`.

## Безопасность

- `*.xlsx`, `*.xls`, `*.csv`, `*.pdf` и временные выгрузки исключены из Git;
- ФИО и номер договора используются только в памяти;
- публичные артефакты проходят отдельный privacy-скан;
- сайт статический: без авторизации, загрузки Excel в браузер и серверного хранилища.
